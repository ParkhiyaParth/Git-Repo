# Git-Repo

A Git and GitHub learning repository created to practice version control commands, repository management, commits, branches, and basic collaboration workflow.

## Project Overview

This repository is focused on learning how Git works in real development. It can be used to practice common version control operations such as creating repositories, tracking changes, committing code, pushing code to GitHub, and managing project history.

## What This Repository Covers

- Initializing and managing Git repositories
- Adding, committing, and pushing changes
- Understanding working directory, staging area, and commit history
- Practicing GitHub repository structure
- Learning basic collaboration workflow
- Maintaining documentation using Markdown

## Tech Stack / Tools

- Git
- GitHub
- Markdown
- Command Line / Terminal

## Basic Git Commands Practiced

```bash
git init
git status
git add .
git commit -m "message"
git branch
git checkout -b feature-branch
git remote add origin <repo-url>
git push origin main
```

## How to Use This Repository

1. Clone the repository:

```bash
git clone https://github.com/ParkhiyaParth/Git-Repo.git
```

2. Move into the project folder:

```bash
cd Git-Repo
```

3. Check Git status:

```bash
git status
```

4. Make changes, stage them, and commit:

```bash
git add .
git commit -m "Update practice files"
```
